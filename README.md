# SUPER AI Community - Stakeholder Connect

![SUPER AI](/public/vite.svg)

An ultra-modern, highly interactive web application designed for the **TCET SUPER AI Community**. This platform features immersive 3D graphics, cyberpunk-inspired UI/UX, hardware-accelerated animations, and dynamic theme switching.

## ✨ Key Features

- **Immersive 3D Cursor Tracking:** Interactive 3D robot/element built with React Three Fiber.
- **Dynamic Theming:** Seamless switching between "Cyber" (Deep space/blue) and "Hacker" (Terminal green) modes.
- **Hardware-Accelerated Backgrounds:** 
  - GSAP-powered floating orbs and dust particles.
  - Complex mesh gradients.
  - 3D perspective cyber-grid floor.
- **Interactive UI Elements:** 
  - Magnetic buttons that react to cursor proximity.
  - Custom fluid cursor trail.
  - CSS keyframe glitch hover effects.
  - Typing audio feedback simulating a terminal experience.
- **Parallax Scrolling:** Background elements and icons that move relative to scroll position using GSAP ScrollTrigger.
- **Responsive Layout:** Beautiful glassmorphism components tailored for both desktop and mobile.

## 🛠️ Tech Stack

This project was built with a cutting-edge modern frontend stack:

- **Core Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) (using native `@theme` configurations)
- **Animations (DOM):** [GSAP (GreenSock)](https://gsap.com/) & [Framer Motion](https://www.framer.com/motion/)
- **3D Graphics:** [Three.js](https://threejs.org/) & [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber)
- **Icons:** [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

To run this project locally, ensure you have Node.js installed on your machine.

1. **Clone the repository:**
   ```bash
   git clone <your-github-repo-url>
   cd superai
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.
